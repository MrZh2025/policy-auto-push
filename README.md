# 医药健康产业集团政策监测信息系统

> 严格遵循《党政机关公文格式》（GB/T 9704-2012）国家标准与 NMPA 权威政务设计规范。集成 **DeepSeek** 大模型政策智能研判，支持一键导出标准公文 Word 简报到本地。

---

## 🌐 在线访问 (GitHub Pages 永久免费公网地址)

👉 **系统公网访问网址**：[https://mrzh2025.github.io/policy-auto-push/](https://mrzh2025.github.io/policy-auto-push/)

- **全网免登录访问**：任何人打开网址即可查阅前沿医药政策与文号检索；
- **纯前端智能研判**：支持在网页右上角配置个人 API Key（DeepSeek / 通义千问 / OpenAI），直接进行一对一深度政策内参咨询；
- **全自动数据流**：每个工作日云端爬虫自动抓取并更新 `docs/data/` 静态数据，公网网页实时同步呈现最新政策！

---

## 🌟 核心功能板块

1. **6 大核心前沿赛道监测**：
   - ⚛️ **核医药与放药监管**：医用同位素、靶向放药、堆照产能建设
   - 🧠 **脑机接口与前沿器械**：脑机接口、神经调控、智能假肢与康复设备
   - 🧬 **AI制药与大模型算法**：计算生物学、算法制药、虚拟筛选
   - 🤖 **医疗机器人与智能装备**：手术机器人、外骨骼、手术导航
   - 💳 **医保集采与支付方式**：医保目录谈判、DRG/DIP支付改革、带量采购
   - 📑 **科技创新与资金申报**：研发后补助、重大专项、创新平台与资金申报
2. **四川省生物医药科技奖补周回顾（红头专项）**：
   - 包含 **5 大核心分析模块**（本周要点摘要、新增政策清单、影响与机遇判断、建议下一步行动、需跟踪不确定事项）；
3. **符合国家标准的公文 Word 简报自动生成**：
   - 严格遵循 **GB/T 9704-2012** 国家公文标准（2号小标宋标题、3号黑体一级标题、3号方正仿宋正文、固定行距28.5磅、标准三线表、无落款无抄送、两端奇偶页码 `— 1 —`）；
   - 本地自动保存到 Windows 电脑桌面，云端自动生成 Artifacts 附件可一键下载；
4. **多通道微信自动推送**：
   - 每天早晨 08:30 和傍晚 17:30 自动向个人微信派发今日医药政策早报。
